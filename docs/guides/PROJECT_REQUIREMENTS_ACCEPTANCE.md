## 启动与入口

已有共享服务请先确认没有正在执行的任务，再由维护者安排加载新代码；不要在原端口重复启动。独立本地启动可在项目根目录使用现有环境执行：

```powershell
python -m uvicorn server.main:app --host 127.0.0.1 --port 8000
```

服务启动会按REQ-1幂等增加项目要求列。打开 http://127.0.0.1:8000 ，使用已有human账号的登录密钥登录，选择项目→“角色”→右侧“项目开发要求”。密钥由现有管理员提供，沿用原账号，不需要新测试账号；不要把密钥写入项目要求。

## 核心验收

1. 输入本人确认的角色职责与交叉复核约定（可含中文、换行、emoji），保存后刷新，内容应一致。占位示例不会自动保存；当前没有替你写入真实项目要求。
2. 修改内容不保存，切换角色/任务/群聊再回角色，草稿应保留；切到群聊后编辑区应隐藏。跨项目往返草稿各自保留且标注未保存。
3. 保存中继续输入，新草稿应保留并提示仍未保存；“放弃修改”恢复最近已确认保存内容。清空后显式保存，再刷新应为空。
4. 超过20000码点时不能保存；断网或服务错误时保留草稿、显示失败，不能显示假成功。普通中文与emoji按字符计数。
5. 使用已有agent账号时只能查看。检查桌面与窄屏布局，编辑区不得遮挡角色列表，任务/群聊原操作正常。
6. 需要验证主控接入时，在更新后的MCP调用talk_list_agents确认当前项目顶层development_requirements为刚保存的文本；新委派任务正文应有派发时快照，修改项目要求不改变旧任务。正式派发仍需遵守正常任务授权。
