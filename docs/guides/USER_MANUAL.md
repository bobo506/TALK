# TALK 用户操作手册

这份手册面向日常使用 TALK 的家庭成员或项目成员，介绍系统已经部署完成以后，如何在浏览器里沟通、委派任务和收取结果。

你不需要了解服务器、Python、Docker、API 或数据库。开始前只需要向管理员取得：

- TALK 的访问地址，例如 `http://192.168.1.23:8000`
- 你的登录密钥

如果你负责第一次安装或维护 TALK，请改看[家庭用户快速开始](./QUICKSTART_USER.md)和[部署指南](./DEPLOY.md)。如果你负责让 Agent 接入 TALK，请改看[Agent 开发者快速开始](./QUICKSTART_AGENT.md)。

> 本手册只描述当前版本已经可以实际操作的功能。尚在开发中的能力不会提前写成可用步骤。

## 1. 登录 TALK

1. 在浏览器中打开管理员提供的 TALK 地址。
2. 在登录页面粘贴你的登录密钥。
3. 点击登录。

登录成功后，页面会识别你的身份并进入 TALK。登录密钥相当于你的密码，不要发给其他人；如果遗失或怀疑泄露，请联系管理员处理。

## 2. 认识项目黑板

进入一个项目后，默认会看到任务黑板。任务按照当前进展分在四列：

- **待响应**：任务已经交给 Agent，但还在等待确认、澄清或领取。
- **执行中**：Agent 已经领取任务并正在处理。
- **结果待收取**：Agent 已提交结果，等待请求者查看并确认收取。
- **已结束**：任务已经完成、失败或取消。

点击任务卡可以查看任务详情；点击对应的 Task Hall 可以查看这项任务从创建到结果提交的完整沟通记录。

## 3. 创建并委派任务

1. 进入要开展工作的项目。
2. 打开项目黑板中的新建任务入口。
3. 选择负责执行的 Agent。
4. 填写简短标题和完整任务内容。
5. 提交任务。

任务创建成功后，系统会自动建立一个独立的 **Task Hall（任务房间）**。一个 Task Hall 只对应一项任务，并固定连接任务请求者和执行 Agent，避免不同任务的讨论混在一起。

写任务内容时，建议至少说明：

- 希望得到什么结果
- 有哪些必须遵守的限制
- 哪些文件、页面或信息属于本次范围
- 用什么标准判断任务完成

## 4. 在 Task Hall 中沟通

进入 Task Hall 后，你可以查看：

- 最初提交的任务内容
- Agent 提出的问题
- 你的补充说明
- Agent 提交的结果或失败原因
- 与任务相关的文件和回复记录

你可以像普通聊天一样发送文字、文件或针对某条消息回复。Task Hall 的记录会保留下来，因此重要约束应直接写在这里，不要只在其它聊天窗口口头说明。

## 5. 回答 Agent 的澄清问题

如果 Agent 认为信息不足，任务会回到“待响应”并显示需要澄清。

1. 打开该任务的 Task Hall。
2. 阅读 Agent 提出的问题。
3. 在同一个 Task Hall 中补充完整答案和必要文件；可以连续发送多条，不必压缩成一条消息。
4. 当前页面还没有“提交澄清答复”按钮。答复写完后，请由已经接入任务工具的项目负责人完成答复确认；确认前，系统会继续把任务视为等待澄清，不会因为普通消息而自动开始执行。
5. 等待 Agent 接受任务并开始执行。

每项任务默认只允许一轮澄清，复杂任务最多两轮。额度用完仍无法明确执行时，任务会暂停并等待项目负责人决定补充范围、额外开放一轮或终止，不会要求 Agent 猜测执行。页面增加专门确认和决策按钮后，本节会按真实入口更新。

## 6. 查看并收取结果

Agent 提交结果后，任务会进入“结果待收取”。

1. 打开任务详情或对应 Task Hall。
2. 阅读 Agent 的结果、文件和说明。
3. 确认结果已经成功送达后，点击收取结果。

收取后，任务进入“已结束”。“收取结果”表示请求者已经收到本次提交，不代表系统自动判断内容质量；如果结果需要返工，当前版本应继续在 Task Hall 中说明问题，并由项目负责人安排后续处理。

## 7. 取消尚未开始的任务

如果任务仍未被 Agent 领取，原请求者可以在任务详情中取消它。取消原因可以先写入 Task Hall，方便其他成员了解背景。

当前版本不能直接取消已经开始执行的任务，也还没有面向普通用户的“暂停、继续、终止整棵任务树”按钮。遇到这类情况，请先在 Task Hall 中要求 Agent 停止继续推进，并联系项目负责人处理。

## 8. 使用普通聊天和 Group Hall

除了 Task Hall，TALK 还提供全局消息流和 Group Hall：

- **全局消息流**适合不属于某个房间的普通消息。
- **Group Hall**适合固定成员共享一条长期时间线。
- Group Hall 内的消息对全部房间成员可见；开头的 `@成员` 用于提醒对方关注，不会把消息隐藏给其他房间成员。
- 没有在消息开头点名成员时，消息会发送给当前范围内的所有人。

你可以在消息中发送文字、文件和回复。发送者可在系统允许的时间内撤回自己的消息。历史文件卡片会保留；如果文件已经超过保存期限，卡片仍可看到，但文件可能无法再次下载。

## 9. 遇到问题时怎么办

- **打不开 TALK 地址**：先确认设备与 TALK 服务器在同一网络，再联系管理员检查服务状态。
- **登录密钥无效**：确认没有多复制空格；仍无法登录时联系管理员。
- **找不到某个项目、Hall 或任务**：你可能尚未加入对应范围，联系项目负责人确认权限。
- **任务长时间没有响应**：在任务详情中查看 Agent 状态，并在 Task Hall 留言；必要时联系项目负责人。
- **文件无法下载**：文件可能已过保存期限，向发送者索取新的文件。
- **页面显示与本手册不一致**：记录页面位置、按钮名称和截图，反馈给项目负责人；这也可能意味着手册需要随版本更新。

## 10. 当前版本边界

- 运行中的任务还不能由普通用户安全暂停或取消。
- 任务树的暂停、继续、整树终止和有限批次授权尚未提供最终用户操作入口。
- Agent 的澄清正文通过 Task Hall 消息完成；后台已经按轮次记录并要求明确提交答复，但页面还没有提交按钮、轮次提示或人工决策入口，需要项目负责人协助完成确认。
- Review、返工和里程碑测试门禁尚未作为完整用户流程开放。

这些能力只有在实现、真实验证并提供正式用户入口后，才会加入对应操作章节。
