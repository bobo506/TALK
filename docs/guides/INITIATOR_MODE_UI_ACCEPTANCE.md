  python -m uvicorn server.main:app --host 127.0.0.1 --port 8000

## 核心验收

1. **固定主控入口退役**：项目设置依次显示“项目开发要求”“调度模式”。没有主控候选框、指定/解除按钮、指定状态摘要；角色列表和详情没有固定主控徽标。点击具体角色只显示角色详情，再回“项目设置”能看到两块项目设置。
2. **发起者语义**：开发要求说明派发前由任务发起者读取；模式说明只约束任务发起侧，执行/复核角色正常执行收到的任务。保存“主动”仍只是项目意向，“实际执行”仍显示尚无生效的主动调度；它不会自动唤醒已结束的对话。模式保存不再要求先指定主控。
3. **未保存离页复位**：读到“已保存设置：被动”后点“主动”，不保存；分别切到任务、群聊、某个角色，再回项目设置，选中项应恢复“被动”。如果初始已保存主动，则反向测试。停留同一面板普通重绘时，未保存选择应保留。
4. **显式保存与显示**：选择另一模式，点“保存”，等成功提示及“已保存设置”更新；离页返回仍应选已保存的模式。已保存一行只有模式名称，无括号或版本。测试结束可明确保存回希望使用的模式；每次保存仍不会自动开始主动任务流程。
5. **原页面保持正常**：角色说明、项目开发要求仍可按原方式查看/保存；任务查看、成果展开/收起、子任务入口、群聊与切项目可用。一次只编辑当前需要验收的内容，避免把其它草稿变化误当模式保存。

## 可选边界（无条件可记未人工验证）

- **Agent只读**：仅使用管理员提供的现有 Agent 密钥登录，模式可查看，选择/保存禁用且显示由项目负责人管理；真人账号可编辑。角色标签本身不改变鉴权。
- **键盘与窄屏**：键盘能到达两个模式选项与保存按钮，radio 可选；窄窗口无遮挡，项目设置/角色详情切换正常。
- **两个窗口陈旧版本冲突/冲突后读取失败**：按 [用户手册“调整项目调度模式”](USER_MANUAL.md#调整项目调度模式) 的受控步骤检查。无故障条件无需制造断网；读取失败应只读重试、成功前暂禁保存。此项已有代码/恢复探针证据，真实 HTTP 并发尚未人工验证。
- **保存请求在途离页**：已有 VM/生命周期回归覆盖真实响应入账；人工没有稳定条件可标未验证，不把离页自动理解为保存被取消。
