## 本轮页面基础验收

1. 强制刷新后进入“角色”，确认已有名称、介绍、绑定与任务入口保持；搜索旁有“全部启动”，列表每角色仅展示当前服务状态，启动/关闭按钮与状态明确区分，条目底边线不压住标签。详情保留启动/关闭与必要提示，服务状态仅在列表展示；绑定信息继续显示。页面/服务加载本身不自动启动角色。
2. 查看未配置、控制能力未知或外部会话角色：启动应禁用或明确说明不可启动原因，批量请求遇到这些角色可明确失败；不能仅因已有绑定或提交了请求就显示“启动成功”。若项目全是这类角色，本轮不要求真实模型成功启停。
3. 点击“全部启动”，核对启动请求/已启动/启动中/跳过/失败的数量和角色结果。已提交且未有就绪证明应显示启动中；真实后到失败应收敛为失败。失败且进程仍受管时提示先关闭，不重复启动；关闭后才可重试安全失败项。
4. 对已具备受管启动条件的测试角色，人工启动、关闭：关闭完成显示“未启动（已关闭）”；其他角色的结果和任务状态保持。切到任务/其他项目/另一账号再返回，应只显示当前项目与账号的状态，不串入旧请求结果。

步骤3–4若缺少已适配测试角色，可记录“未人工验证”，不为验收改真实模型/账号或猜运行器配方。此时本轮人工结论只覆盖控件、禁用/失败说明、已有角色保持与状态展示；真实成功启停留到对应运行器适配验收。关闭TALK自动清理服务属于R1-4。
