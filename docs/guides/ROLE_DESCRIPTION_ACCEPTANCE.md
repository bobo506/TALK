# 角色说明功能验收

更新：2026-10-05。后端与前端独立复核通过，等待人工页面验收。

## 启动与入口

已运行服务时先确认加载了本轮后端；旧服务需在空闲时重启。未运行时，在项目根目录执行：

    python -m uvicorn server.main:app --host 127.0.0.1 --port 8000

打开 http://127.0.0.1:8000/ ，使用原有human账号的TALK API Key或当前登录状态，选择项目→角色→具体角色。按Ctrl+F5加载资源版本20261005-role-desc-f1-fix。无需创建新账号或复制密钥到任务消息。

## 核心验收步骤

1. 确认顺序为角色名称、角色说明、参与任务，项目设置仍独立显示。
2. 输入两行自定义说明并保存，确认列表摘要立即改变，刷新后仍保留；详情不残留原职责标签。
3. 编辑时停留超过5秒并切换角色/项目后返回，确认草稿保留；有任务数据变化时确认焦点、光标和输入不跳动。
4. 点击恢复默认，确认详情和列表回到原文；保存空白也应恢复默认。长非空说明超过2000字符应提示超限。
5. 用较长首行检查列表最多两行截断、窄窗口不撑破布局；输入HTML字样应显示文字。
6. 确认参与任务的筛选、查看和耗时仍正常，项目设置的主控/开发要求未受影响。若已有agent账号，可验证说明只读、可以复制。

## 已验证与限制

- #138独立复跑Node148、页面契约9、后端相关104及3项新增探针通过；后端#134独立审查通过。
