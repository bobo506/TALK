# AGENTS.md 结构化精简设计

## 目的与现状

`AGENTS.md` 是每次项目会话自动加载的规则入口，应保留长期有效的身份、协作、验证和收尾约束。当前文件有498行、67,729个Unicode字符、137,844字节，其中“当前 Agent 角色”一节占49,958字符，大量带日期的任务状态、测试数量、进程信息和历史分工与进度、交接、验收文档重复，影响固定上下文容量。

## 已选方案

采用结构化精简，而不是只删除顶部几条记录：

- `AGENTS.md` 只保留当前授权、长期规则、文档索引和开发约定。
- 当前任务事实以 `docs/PROGRESS.md`、`docs/HANDOFF_20261028.md` 和对应验收文档为准。
- 已完成事项和历史分工以 `docs/PROGRESS_HISTORY.md` 及原任务包为准。
- 后续开发只链接 `docs/spec/DEVELOPMENT_ROADMAP.md`，不复制待办清单。
- 使用说明和协作亮点只链接 `docs/guides/USER_MANUAL.md`，不复制正文。
- 已在其他正式文档或Git历史中完整保存的事实不重复迁移；发现现行约束只存在于旧文件时才保留或转写，不直接丢失。

曾考虑只压缩“当前 Agent 角色”一节，虽然能降到约20,000字符，但会保留重复和相互冲突的分工规则，因此未采用。

## 目标结构

1. 开发者指引与文档入口。
2. 当前身份、348交接点和本次授权边界。
3. 任务分工、切片确认、隔离写入、独立复核和集中返修。
4. 发起者主被动、交付、收取、进度、Git和人工验收。
5. 终端适配、编码、文档语言、技术栈和启动方式。

目标为6,000–16,000个Unicode字符；篇幅是结构检查指标，不能为达字数删除现行约束，也不为达到预估下限保留重复说明。

## 不变项

- 不修改产品源码、测试、348候选/冻结材料或任务状态。
- 不改项目页面开发要求、角色绑定、Key、生产配置或服务。
- 不重写路线图、用户手册、进度历史和348验收报告。
- 不自动派发348返修、DeepSeek复核或其它任务。
- 保留每个新切片先确认、单一写入方、独立复核、原始证据、人工验收和权限边界。

## 验证

- 统计精简后的行数、字符和字节，确认目标区间。
- 检查当前角色、348两项失败、2994收取权限和本次仅文档授权仍有准确入口。
- 检查新切片确认、冻结单写方、独立复核、集中返修、默认被动、进度/Git、人工验收等关键规则未丢失。
- 检查所有相对Markdown链接存在，`git diff --check`通过，差异仅限本设计、计划和`AGENTS.md`。
- 这是纯文档变更，不运行业务测试；提交前审阅最终diff，确认没有把历史进度重新写回规则入口。
